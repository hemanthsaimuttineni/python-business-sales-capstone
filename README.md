# 🐍 Python Business Sales Capstone

Month 1 Python Capstone Project focused on applying Python fundamentals to a practical business scenario.

## 📌 About the Project

This project was developed as the final capstone for my **Month 1 Python learning journey**.

The project applies Python programming concepts to business calculations such as revenue, cost, profit, and profit margin.

It also demonstrates how to organize Python code into multiple files using custom modules.

## 🎯 Project Objectives

- Accept business values from the user
- Calculate profit
- Calculate profit margin
- Identify whether the business has a profit or loss
- Organize reusable functions into Python modules
- Practice Python fundamentals through a practical project

## 🛠️ Python Concepts Used

- Variables
- Data Types
- User Input
- Conditional Statements
- Functions
- Parameters and Arguments
- Return Values
- Modules
- Custom Python Modules
- Mathematical Calculations
- Formatted Output
